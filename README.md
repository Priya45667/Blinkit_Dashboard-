
# Blinkit Sales Analysis Dashboard

## Project Overview

The objective of this project is to analyze Blinkit's sales performance and identify key business insights related to product sales, outlet performance, customer ratings, and item distribution. This dashboard helps businesses understand sales trends and supports data-driven decision-making.

The dashboard was developed using **Microsoft Power BI** and **Microsoft Excel** to transform raw sales data into meaningful business insights through interactive visualizations and KPIs.

Throughout this project, I had the opportunity to:

- Analyze Blinkit's sales dataset to identify business trends.
- Build an interactive Power BI dashboard.
- Create KPIs for sales analysis.
- Visualize product performance across different outlet types and locations.
- Improve my skills in Power BI, Excel, and dashboard design.



# Tools Used

- Microsoft Power BI
- Microsoft Excel


# Steps Followed

## 1. Data Gathering

- Imported the Blinkit sales dataset into Microsoft Power BI.
- Reviewed the dataset before starting the analysis.


## 2. Data Cleaning

Data cleaning was performed by:

- Removing duplicate records.
- Handling missing values.
- Correcting data types.
- Renaming columns where required.
- Preparing the dataset for visualization.


## 3. Data Processing

Several KPIs were created to summarize the overall business performance.

### KPIs Created

- Total Sales
- Average Sales
- Number of Items
- Average Rating

These KPIs provide a quick overview of Blinkit's sales performance.


## 4. Data Analysis

The dashboard was developed using different Power BI visualizations including:

- KPI Cards
- Line Chart
- Donut Chart
- Bar Chart
- Funnel Chart
- Matrix Table
- Interactive Slicers

These visualizations help users understand sales trends, outlet performance, and customer behavior more effectively.

# Key Insights Summary

- Blinkit generated a **Total Sales of $1.20M** from **8,523 items** with an **Average Sales of $141** and an **Average Rating of 3.9**.
- Regular fat-content products contributed a higher percentage of total sales compared to low-fat products.
- Fruits & Vegetables and Snack Foods were the top-performing item categories in terms of total sales.
- Medium-sized outlets generated the highest sales, followed by small and high-sized outlets.
- Tier 3 outlet locations recorded the highest revenue compared to Tier 1 and Tier 2.
- Outlet establishments reached their highest sales in **2018**, generating approximately **$205K**.
- Supermarket Type 1 contributed the highest sales among all outlet types.
